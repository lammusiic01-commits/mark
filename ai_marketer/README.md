# 🤖 AI Маркетолог — Premium Telegram Mini App

**Управление Яндекс.Директом прямо в Telegram.** Бот присылает отчёты, приложение
считает, где утекает бюджет, и предлагает конкретные действия в рублях: поднять
или снизить ставку, отключить город, убрать фразу, включить ретаргетинг.

Внутри — 8 расчётных модулей движка, интеграции Яндекс.Директа и Метрики,
детектор ботового трафика, генератор гипотез, AI-советник на OpenRouter
(только тексты — все цифры считает код) и приём оплаты по СБП с QR-кодом.

```
Telegram-бот → кнопка «Открыть маркетолога» → Mini App (Vue 3) → FastAPI → движок + Яндекс
```

## ⚡ Быстрый старт (одна кнопка)

### Windows

```
1. Установите Docker Desktop: https://www.docker.com/products/docker-desktop
2. Распакуйте архив в папку без кириллицы в пути (например C:\ai-marketer)
3. Двойной клик по start.bat
4. Заполните secrets.env (файл откроется сам) и запустите start.bat снова
```

### Linux / macOS

```bash
chmod +x start.sh
./start.sh          # при первом запуске создаст secrets.env и откроет его
```

Скрипт делает всё сам: проверяет Docker, создаёт `secrets.env` из шаблона,
**генерирует `ENCRYPTION_KEY`**, собирает образы (включая сборку Mini App),
поднимает PostgreSQL и Redis, применяет миграции и запускает API, бота и WebApp.
Ручные команды, установка Python-пакетов и запуск миграций не нужны.

После запуска:

| Что | Где |
|---|---|
| Документация API | http://localhost:8000/docs |
| Проверка живости | http://localhost:8000/health |
| WebApp | http://localhost:8000/ (API сам раздаёт собранный интерфейс), дублирующий адрес nginx — http://localhost:3000 |

### Остальные кнопки

| Команда | Действие |
|---|---|
| `start.bat` / `./start.sh` | запустить всё |
| `stop.bat` / `./stop.sh` | остановить (данные в томах сохраняются) |

## 🔑 Файл секретов

Единственный файл с ключами — **`secrets.env`** в корне проекта. Он создаётся
автоматически из `secrets.env.example` и уже внесён в `.gitignore`: в
репозиторий уходит только шаблон.

| Переменная | Обязательна | Что это |
|---|---|---|
| `BOT_TOKEN` | да | токен бота от @BotFather (`/newbot`) |
| `WEBAPP_URL` | да | HTTPS-адрес приложения (ngrok на локалке, ваш домен на сервере) |
| `TELEGRAM_PROXY_URL` | да | прокси к Telegram — уже заполнен рабочим Worker’ом для РФ |
| `OPENROUTER_API_KEY` | да | бесплатный ключ: https://openrouter.ai/keys |
| `AI_MODEL` | нет | модель для текстов; по умолчанию бесплатная Llama 3.3 70B |
| `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD` | да | значения для локального Docker уже готовы |
| `REDIS_HOST`, `REDIS_PORT` | да | значения для локального Docker уже готовы |
| `ENCRYPTION_KEY` | да | **генерируется автоматически** при первом запуске |
| `SBP_MERCHANT_ID`, `SBP_ACCOUNT`, `SBP_SECRET_KEY` | нет | реквизиты СБП; без них баланс пополняется в тестовом режиме |
| `API_PORT`, `WEBAPP_PORT` | нет | порты, по умолчанию 8000 и 3000 |
| `ENV`, `LOG_LEVEL` | нет | режим (`production`) и подробность логов (`INFO`) |

**Про `ENCRYPTION_KEY`.** Им шифруются токены Яндекс.Директа и Метрики перед
записью в базу (Fernet: AES-128-CBC + HMAC-SHA256). Сохраните копию ключа в
надёжном месте: если он потеряется, подключения придётся создавать заново.

**Про безопасность.** Ключи не попадают ни в код, ни в docker-образ, ни в логи:
контейнеры получают их через `env_file`, логгер вырезает значения с именами
`token`, `secret`, `password`, `key`, а сборщик релиза проверяет архив на
случайное попадание `secrets.env`.

## 📱 Как это работает

### Бот (`bot/`)

- `/start` — приветствие и кнопка **«Открыть маркетолога»** (WebApp);
- `/help` — что умеет, как подключить сервисы;
- `/status` — короткая сводка по подключениям и балансу;
- уведомления: утренняя сводка (расход, заявки, цена заявки), тревога при
  всплеске накрутки, новые гипотезы, предупреждение о низком балансе.

Все обращения к Telegram идут **через прокси из `secrets.env`**
(`TELEGRAM_PROXY_URL`) — прямых вызовов `api.telegram.org` в коде нет: из РФ
это единственный рабочий путь. Подпись `initData` проверяется HMAC-SHA256
(`api/auth.py`), без неё API отвечает 401.

### Mini App (`webapp/`) — 9 экранов

| Экран | Что делает |
|---|---|
| **Онбординг** | 5 шагов: знакомство, 4 возможности, инструкции «где взять ключ», безопасность, готовность |
| **Подключения** | 3 карточки: Директ, Метрика, сайт; проверка токена на месте, паспорт сайта (платформа, HTTPS, счётчик Метрики) |
| **Главная** | приветствие, баланс, 4 метрики (клики, заявки, цена заявки, расход), 4 быстрых действия, AI-совет |
| **Ловля ботов** | круговая шкала риска, экономия в рублях, паттерны по критичности, график за 30 дней, план действий |
| **Гипотезы** | карточки по приоритету, «Запустить» / «Объяснить» / «Отклонить», суммарный потенциал |
| **Кампании** | список с переключателем, синхронизация с Директом, шторка с планом: ставки, бюджет, цель по заявке |
| **Баланс** | пресеты и своя сумма, QR-код СБП, опрос статуса, история операций |
| **Отчёты** | аудит сайта, география, рынок и конкуренты, детектор ботов, гипотезы |
| **Настройки** | профиль бизнеса (ниша, регион, бюджет, цель по заявке), уведомления, сервисы, удаление аккаунта |

В интерфейсе: стеклянные карточки на чёрном фоне, нижняя навигация, шторки со
свайпом, haptics на каждое действие, `Intl.NumberFormat('ru-RU')` для денег,
safe-area для iPhone, `enableClosingConfirmation()` против случайного закрытия.

### Движок (`engine/`) — 8 модулей

| Модуль | Что считает |
|---|---|
| `bot_detector` | накрутка: мгновенные отскоки, ровные интервалы, роботный трафик Метрики; утечка в рублях и экономия в месяц |
| `bid_optimizer` | новые ставки по цене заявки: −40 %…+30 % от текущей, шаг и границы учитываются |
| `hypothesis_engine` | гипотезы роста с оценкой эффекта в рублях и приоритетом (impact × усилие × уверенность) |
| `seo_analyzer` | аудит страницы: заголовки, мета, скорость, мобильная версия, счётчик Метрики, быстрые правки |
| `geo_analyzer` | города: где заявка дороже цели (снизить или отключить), где дешевле (усилить) |
| `market_analyzer` | ориентиры по нише: цена клика, конкуренция, план бюджета под цель по заявке |
| `budget_allocator` | раскладка бюджета между кампаниями и прогноз заявок на месяц |
| `campaign_manager` | синхронизация кампаний, состояния, бюджеты, применение решений |

### AI-советник (`ai/`)

OpenRouter с бесплатными моделями и автоперебором при отказе
(`llama-3.3-70b`, `gemini-2.0-flash-exp`, `deepseek-chat-v3.1`, `qwen-2.5-72b`).
Отвечает только за текст: числа берутся из расчётов, а каждая цифра в ответе
сверяется с фактами (±1) — «придуманные» цифры отбрасываются. Нет ключа или
интернета — подставляется расчётный шаблон, приложение продолжает работать.

### Платежи (`payments/`)

СБП: счёт, QR-код (PNG в base64), ссылка на оплату, срок жизни 60 минут,
опрос статуса, зачисление на баланс, журнал операций. Без реквизитов СБП
работает тестовый режим — кнопка «Проверить оплату» зачисляет вручную.

## 🧪 Разработка и тесты

### Проверка интерфейса без Docker

```bash
# 1. API на SQLite: нужен только Python 3.11+ и зависимости
python3 -m venv .venv && source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python3 dev_server.py                                  # http://localhost:8000

# 2. Mini App с горячей перезагрузкой
cd webapp
npm install
npm run dev                                            # http://localhost:3000
```

В режиме разработки сервер создаёт демо-данные (`/api/dev/seed`) и выдаёт
тестовый вход (`/api/dev/sign-in`), поэтому приложение смотрится целиком:
подключения, кампании, отчёт по ботам, гипотезы, баланс. В боевом режиме эти
адреса не существуют (в `ROUTERS` их нет при `ENV=production`).

### Тесты

```bash
# Python: 99 проверок — ядро, движок, сервисы, AI, API, поставка, демо-режим
python -m pytest tests -q

# Mini App: 23 проверки на живом API (нужен запущенный dev_server.py)
cd webapp && npm test
```

Тесты Mini App проверяют каждый из 9 экранов и сценарии пользователя:
подключение и отключение сервисов, синхронизацию кампаний и правку ставок,
поиск гипотез, отчёт по ботам, пополнение баланса. Если API не запущен,
проверки экранов пропускаются, шаблонные тесты продолжают работать.

### Полезные команды

```bash
./logs.sh bot                                  # логи бота
docker compose --env-file secrets.env --profile migrate run --rm migrate
docker compose --env-file secrets.env --profile api run --rm api alembic revision --autogenerate -m "изменение"
docker compose --env-file secrets.env --profile api run --rm api pytest -q
```

## 🤖 Подключение Telegram (5 минут)

1. **Бот.** @BotFather → `/newbot` → скопируйте токен в `BOT_TOKEN`.
2. **WebApp.** Telegram откроет приложение только по HTTPS:
   - локально: `ngrok http 8000` → полученный адрес в `WEBAPP_URL`;
   - на сервере: ваш домен с сертификатом.
3. **Кнопка.** @BotFather → `/mybots` → ваш бот → *Bot Settings* →
   *Menu Button* → укажите адрес из `WEBAPP_URL`.
4. **Перезапуск.** `stop.bat`, затем `start.bat` — бот подхватит настройки.
5. **Проверка.** Напишите боту `/start` и нажмите «Открыть маркетолога».

Прокси для Telegram (`TELEGRAM_PROXY_URL`) уже заполнен рабочим адресом — из
России бот работает без VPN. Если адрес перестанет отвечать, поднимите свой
Cloudflare Worker: `deploy/cloudflare-worker/telegram-proxy.js` в репозитории MARK.

## 🩺 Если что-то не так

| Симптом | Причина и решение |
|---|---|
| `Docker не установлен` | Установите Docker Desktop или Docker Engine + Compose v2 |
| `Docker установлен, но демон не запущен` | Запустите Docker Desktop (Linux: `sudo systemctl start docker`) |
| Бот молчит | Проверьте `BOT_TOKEN` и `TELEGRAM_PROXY_URL`, затем `./logs.sh bot` |
| «Откройте приложение из бота» | Открыли WebApp по прямой ссылке: Telegram не передал `initData`. Открывайте через кнопку в боте |
| Приложение не открывается в Telegram | Нужен HTTPS-адрес в `WEBAPP_URL` и кнопка в @BotFather |
| `Вход устарел` | `initData` живёт ограниченное время — откройте приложение заново из бота |
| «Директ не подключён» | Экран «Подключения»: вставьте OAuth-токен, проверка проходит сразу |
| «Токен подключения повреждён» | Сменился `ENCRYPTION_KEY` — подключите сервис заново |
| «Не подключена Метрика» | Отчёты по визитам и ботам требуют счётчик Метрики |
| Нет советов от AI | Проверьте `OPENROUTER_API_KEY`; без него показываются расчётные тексты |
| Пустая страница в браузере | Откройте `http://localhost:8000/` (API раздаёт собранный интерфейс) |
| Платежи в тестовом режиме | Заполните `SBP_MERCHANT_ID`, `SBP_ACCOUNT`, `SBP_SECRET_KEY` |

Логи целиком: `./logs.sh` или `docker compose --env-file secrets.env logs --tail 100`.
