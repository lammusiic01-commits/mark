# MARK Desktop (Electron)

Настольная оболочка MARK. Две задачи:

1. **Панель подключений** — статус API, запуск локального сервера MARK одной кнопкой, настройка адреса API.
2. **Окно входа в сервисы** — Яндекс.Директ, Метрика, Вебмастер, Google Ads/Analytics/GSC, Tilda, WordPress, Vercel, Cloudflare и другие открываются *внутри приложения*: вы входите как обычно (пароль, СМС, капча остаются у вас), MARK забирает cookies домена и отдаёт их серверу. Дальше сервисом управляет платформа.

## Запуск

```bash
npm --prefix apps/desktop install     # или npm run desktop:install из корня
npm --prefix apps/desktop start       # или npm run desktop:start
```

Перед запуском поднимите сервер (`npm run dev` или `npm start`), либо нажмите в панели
«Запустить сервер» — приложение само стартует `apps/server/dist/server.mjs --serve-web`
(если сборки нет, поднимет исходники через tsx).

## Как выглядит рабочий цикл

1. В панели видно: API доступен, локальный сервер работает.
2. В интерфейсе MARK откройте **Подключения** → сервис → **Окно в приложении** → «Открыть».
3. В отдельном окне войдите в аккаунт сервиса.
4. Вернитесь в панель: видно, сколько cookies найдено → **Сохранить сессию**
   (или включите «Автосохранение» — cookies уйдут в MARK сразу, как появятся).
5. В MARK подключение станет действующим, и сервис начнёт работать под вашей сессией.

## Файлы

| Файл | Назначение |
| --- | --- |
| `main.cjs` | главный процесс: окна, IPC, запуск локального сервера, сбор cookies и отправка на `<API>/api/sessions/:id/cookies` |
| `preload.cjs` | мост `window.mark` для интерфейса MARK (`app`, `server`, `login`, `onLog`) |
| `login.html` | панель подключений: статусы, кнопки, журнал |

## Настройки

Сохраняются в `settings.json` в каталоге пользовательских данных Electron (`app.getPath('userData')`).

| Ключ | По умолчанию | Значение |
| --- | --- | --- |
| `apiUrl` | `http://127.0.0.1:8787` | адрес API MARK (веб-интерфейс отдаётся тем же сервером) |
| `appUrl` | адрес API | отдельный адрес интерфейса, если фронтенд поднят на Vite |
| `autoStartServer` | `false` | поднимать локальный сервер автоматически, если API не отвечает |

Флаги командной строки: `--api http://host:8787`, `--url http://host:5173`.

## Сборка установщика

```bash
npm run desktop:dist        # Windows: NSIS + ZIP
npm --prefix apps/desktop run dist:mac
npm --prefix apps/desktop run dist:linux
```

## Безопасность

- Окно входа грузится в отдельной изолированной сессии (`partition: persist:mark-login-<service>`);
  `nodeIntegration` выключен, доступ к системе у страницы сервиса отсутствует.
- Пароли MARK не читает: забираются только cookies того домена, который вы открыли.
- Отправляются cookies на сервер MARK (ваш собственный API), где шифруются AES-256-GCM.
- Закрытие окна приложения останавливает локальный сервер, если он был запущен отсюда.
