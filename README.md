# Чистая сборка: Tenda TX2 + VPS OneDash (Хельсинки, Debian 12) + Windows 11

Полностью переработанный, безопасный и чистый проект для работы **YouTube (4K), Telegram, Instagram, Discord, ChatGPT** на компьютере с **Windows 11** и в домашней сети **Tenda TX2**, а также для мгновенного восстановления базовых настроек сети и работы **Happ VPN**.

---

## Что исправлено и почему эта сборка на 100% безопасна для Windows 11

1. **Никогда не трогает вашу сетевую карту `Ethernet`:**
   - Скрипт **не отключает DHCP**, **не меняет IP-адрес компьютера**, **не меняет системный DNS адаптера** и **не включает серверную службу `RemoteAccess` / `IPEnableRouter`**, из-за которых в прошлой версии пропадал интернет и переставал включаться драйвер **Happ VPN**.
2. **Встроенное восстановление сети и починка Happ VPN (`1-RESTORE-INTERNET.bat`):**
   - Одним кликом сбрасывает все следы прошлых настроек (`IPEnableRouter=0`, `RemoteAccess=Disabled`, `Forwarding=Disabled`, `WinSock Reset`, `DHCP`), полностью возвращая штатную работу интернета и приложения **Happ**.
3. **Никаких ошибок кодировки `cmd.exe`:**
   - Файлы `.bat` содержат только чистый английский ASCII-код, а вся русскоязычная логика работает внутри PowerShell (`UTF-8 with BOM`).
4. **Двойной режим работы с вашим VPS в Хельсинки (`91.108.239.5`):**
   - Автоматически выдаёт готовую ссылку **`vless://...` (Reality XTLS-Vision)** на Рабочий стол (`HAPP-FINLAND-LINK.txt`) и в буфер обмена — вы можете сразу вставить её в **Happ** на ПК и на телефоне;
   - Либо включает фоновый выборочный обход на ПК (где YouTube, Telegram, Instagram, Discord идут через Хельсинки, а `ya.ru`, Сбербанк, Госуслуги и игры идут напрямую).

## Пошаговая инструкция (как пользоваться)

### Шаг 1. Распакуйте скачанный ZIP-архив
Нажмите правой кнопкой мыши по скачанному архиву $\rightarrow$ **«Извлечь все...»** (например, на Рабочий стол или в `C:\tenda`).

### Шаг 2. Восстановите базовые настройки сети и работу Happ VPN
1. Запустите двойным кликом файл **`1-RESTORE-INTERNET.bat`** (подтвердите запуск от имени Администратора).
2. Подождите 5 секунд, пока скрипт напишет `SUCCESS! ALL NETWORK SETTINGS RESTORED TO WINDOWS 11 DEFAULTS!`.
3. *(Рекомендуется один раз перезагрузить ПК после этого, чтобы драйвер WinTun в программе Happ перезапустился на чистом сетевом стеке).*

### Шаг 3. Запустите главное меню (`2-START-GATEWAY.bat`)
Откройте **`2-START-GATEWAY.bat`** — перед вами появится чистое меню:

* **`[1] ВОССТАНОВИТЬ БАЗОВЫЕ НАСТРОЙКИ ИНТЕРНЕТА И ПОЧИНИТЬ HAPP VPN`** — можно нажать в любой момент для возврата всех настроек Windows 11 по умолчанию.
* **`[2] ЗАПУСТИТЬ АВТОМАТИЧЕСКИЙ ВЫБОРОЧНЫЙ ОБХОД`** — подхватывает уже сохранённые ключи вашего VPS (`91.108.239.5`) или подключается к нему по SSH (`порт 55971`), сохраняет на Рабочий стол готовую ссылку `vless://` для Happ и запускает выборочный обход.
* **`[3] ПОЛУЧИТЬ ССЫЛКУ VLESS:// ВАШЕГО СЕРВЕРА`** — копирует вашу личную ссылку `vless://...` от сервера в Хельсинки в буфер обмена Windows и в файл `HAPP-FINLAND-LINK.txt` на Рабочем столе (просто нажмите `+` в программе **Happ** на ПК или телефоне $\rightarrow$ «Вставить из буфера обмена»).
* **`[4] ОСТАНОВИТЬ ВСТРОЕННЫЙ ТУННЕЛЬ`** — отключает фоновый `sing-box`, если вы хотите пользоваться интернетом через приложение **Happ**.
* **`[5] КАК ПОДКЛЮЧИТЬ ТЕЛЕФОНЫ И ТВ ПО WI-FI`** — показывает адрес локального прокси вашего ПК (`:2080`) для домашнего Wi-Fi и ссылку для телефонов.
