# Tenda TX2 Smart Gateway — Полный комплект под Windows 11 + Tenda TX2 (Вариант Б)

Готовый программный комплекс, позволяющий превратить ваш домашний компьютер на **Windows 11** (подключённый кабелем к роутеру **Tenda TX2**) в **прозрачный умный шлюз (Split-Tunneling Gateway)** для всей квартиры/дома:

* **На самом ПК (по кабелю)** и **на всех устройствах по Wi-Fi (смартфоны iOS/Android, Smart TV, ноутбуки, планшеты)** работают **YouTube в 4K без буферизации, Telegram (звонки, кружочки, медиа), Instagram, Threads, Discord (включая голосовые каналы), ChatGPT / Claude** и любые выбранные вами сайты.
* **Ни на одном устройстве дома не нужно включать VPN-приложения.**
* **Весь российский трафик** (Сбербанк, Т-Банк, Госуслуги, Яндекс, VK, Ozon, онлайн-игры, торренты) идёт **напрямую через вашего провайдера** с нулевой дополнительной задержкой (`0.0 мс` на ПК и `< 0.3 мс` по Wi-Fi).
* **Безопасный режим при выключении ПК:** мы специально настроили связку с Tenda TX2 так, что даже если вы полностью выключите компьютер на ночь, домашний Wi-Fi на телефонах **не пропадёт** — обычный интернет продолжит работать через резервный DNS провайдера!

## Как это работает на Windows 11 в паре с роутером Tenda TX2 (`192.168.0.1`)

```text
[Смартфоны / Smart TV по Wi-Fi 6] ──► [Роутер Tenda TX2 (192.168.0.1)]
                                            │
         ┌──────────────────────────────────┴──────────────────────────────────┐
         ▼ (Обычные сайты РФ: .ru, Банки, Госуслуги)                           ▼ (Только FakeIP 198.18.0.0/15 + подсети Telegram)
[Напрямую к провайдеру РФ (0 мс!)]                             [Ваш ПК на Windows 11 по кабелю (192.168.0.2)]
                                                                 ├── Служба Sing-box (Wintun + FakeIP DNS :53)
                                                                 └── Защищённый туннель VLESS-Reality XTLS-Vision ──► Зарубежный VPS
```

В папке **`windows11/`** подготовлены **два варианта запуска на ваш выбор**:
1. **Вариант Б1 (Рекомендуемый — Нативная системная служба Windows 11, `Setup-Windows11-Gateway.ps1`):**
   * Не требует установки тяжёлых виртуальных машин, потребляет **всего ~25 МБ ОЗУ** и **0% нагрузки на процессор**.
   * Автоматически скачивает официальный `sing-box.exe` с драйвером `Wintun`, закрепляет за сетевой картой ПК адрес `192.168.0.2`, включает в ядре Windows 11 маршрутизацию транзитных пакетов (`IPEnableRouter = 1` + `IPv4 Forwarding`), открывает порты `53/UDP` только для домашней сети `192.168.0.0/24` и прописывает тихий автозапуск при включении компьютера.
2. **Вариант Б2 (Изолированная Linux VM / WSL2 Mirrored в режиме Сетевого моста `Bridged Adapter`, `Setup-Windows11-VM-Bridge.ps1` + `Vagrantfile`):**
   * Если вы хотите запустить шлюз внутри изолированной Linux-системы на Windows 11 — скрипт в 1 клик настраивает либо встроенный в Windows 11 23H2/24H2 режим **WSL2 Mirrored Networking**, либо легковесную виртуальную машину **Debian 12 в VirtualBox / Hyper-V (`Bridged Adapter`, IP `192.168.0.2`, 384 МБ ОЗУ)**.

## Пошаговая инструкция по установке (от А до Я за 10 минут)

### Шаг 1. Подготовка зарубежного VPS (3 минуты)
Для работы протокола **VLESS + XTLS-Vision + Reality** (который не блокируется и не замедляется ТСПУ в РФ) нужен любой дешёвый зарубежный VPS (Ubuntu 22.04 / 24.04 или Debian 12).
> **Совет по минимальному пингу из РФ:** выбирайте локацию **Финляндия (Хельсинки)**, **Нидерланды (Амстердам)**, **Швеция (Стокгольм)** или **Германия (Франкфурт)** — пинг составит всего `20–35 мс`.

Подключитесь к VPS по SSH (прямо из терминала Windows 11: `ssh root@IP_ВАШЕГО_VPS`) и выполните:
```bash
git clone <url-этого-репозитория> tenda-gateway
cd tenda-gateway
sudo bash scripts/setup-vps.sh
```
Скрипт сам включит ускорение **TCP BBR**, установит сервер `sing-box`, сгенерирует ключи `Reality` и выведет вам 4 строчки:
* `IP-адрес VPS`
* `UUID`
* `Public Key`
* `Short ID`

---

### Шаг 2. Установка на ваш ПК с Windows 11 (2 минуты)

1. Скачайте (склонируйте) эту папку на ваш компьютер с Windows 11 (например, в `C:\tenda-gateway`).
2. Откройте папку **`windows11`** и запустите двойным кликом файл:
   👉 **`Manage-Gateway.bat`** *(он сам запросит права Администратора Windows 11)*.
3. В открывшемся меню нажмите **`1`** *(«Установить и запустить шлюз на Windows 11»)* — или **`2`**, если предпочитаете запуск внутри виртуальной машины Linux VM (`Bridged Adapter`).
4. Вставьте `IP-адрес VPS`, `UUID`, `Public Key` и `Short ID`, полученные на Шаге 1.

Скрипт `Setup-Windows11-Gateway.ps1` автоматически выполнит всю настройку Windows 11:
* Назначит вашему кабельному подключению статический адрес **`192.168.0.2`** (шлюз `192.168.0.1` — ваш Tenda TX2);
* Включит в реестре и сетевом стеке Windows 11 пересылку пакетов с Wi-Fi устройств (`IPEnableRouter = 1`);
* Скачает `sing-box.exe`, создаст виртуальный интерфейс `SingBoxTun` с защитой от сетевых петель (`inet4_route_exclude_address: 192.168.0.0/16`);
* Запустит службу `TendaSmartGateway-SingBox` и веб-панель управления на **`http://127.0.0.1:8080`** (`http://192.168.0.2:8080`).

> **После этого шага на самом вашем компьютере по кабелю YouTube, Telegram, Instagram, Discord и ChatGPT УЖЕ работают без VPN!**

---

### Шаг 3. Настройка роутера Tenda TX2 (`192.168.0.1`) для всех Wi-Fi устройств (2 минуты)

Чтобы все смартфоны, телевизоры и ноутбуки по Wi-Fi тоже автоматически работали через ваш умный шлюз (и при этом Wi-Fi не отключался, когда компьютер выключен):

1. Откройте в браузере настройки роутера: **`http://192.168.0.1`** (или `http://tendawifi.com`).
2. Перейдите в **«Системные настройки» (System Settings)** $\rightarrow$ **«Настройки локальной сети» (LAN Settings)**:
   * IP-адрес роутера: `192.168.0.1`
   * Галочку **«DHCP-сервер»** оставьте **ВКЛЮЧЁННОЙ**
   * **Первичный DNS-сервер:** `192.168.0.2` *(ваш ПК-шлюз)*
   * **Вторичный DNS-сервер:** `77.88.8.8` *(быстрый DNS Яндекса — подстрахует Wi-Fi, если ПК выключен)*
   * Нажмите **«Сохранить»**.
3. Перейдите в **«Расширенные настройки» (Advanced Settings)** $\rightarrow$ **«Статическая маршрутизация» (Static Routing)** и добавьте строки из таблицы ниже:

| Сеть назначения | Маска подсети | Шлюз | Что именно маршрутизирует |
| :--- | :--- | :--- | :--- |
| **`198.18.0.0`** | **`255.254.0.0`** | **`192.168.0.2`** | **ВСЕ домены из списков (YouTube 4K, Instagram, Discord, ChatGPT и др. через FakeIP)** |
| **`149.154.160.0`** | **`255.255.240.0`** | **`192.168.0.2`** | **Telegram (звонки, кружочки, медиа, DC2/DC4)** |
| **`91.108.4.0`** | **`255.255.252.0`** | **`192.168.0.2`** | **Telegram (DC1/DC3)** |
| **`91.108.8.0`** | **`255.255.252.0`** | **`192.168.0.2`** | **Telegram** |
| **`91.108.12.0`** | **`255.255.252.0`** | **`192.168.0.2`** | **Telegram** |
| **`91.108.16.0`** | **`255.255.252.0`** | **`192.168.0.2`** | **Telegram** |
| **`91.108.56.0`** | **`255.255.252.0`** | **`192.168.0.2`** | **Telegram (DC5)** |
| **`95.161.64.0`** | **`255.255.240.0`** | **`192.168.0.2`** | **Telegram CDN** |

4. На телефоне выключите и снова включите Wi-Fi (чтобы телефон обновил DNS от роутера) — **готово!**

## Проверка и управление на Windows 11

В любой момент вы можете:
* Запустить **`windows11\Manage-Gateway.bat`** и нажать **`4`** — скрипт `Check-Gateway-Health.ps1` проверит связь с Tenda TX2, работу службы `sing-box.exe`, протестирует FakeIP на `youtube.com`, прямой маршрут на `sberbank.ru` и пинг до VPS.
* Открыть в браузере **`http://127.0.0.1:8080`** (или с телефона по Wi-Fi **`http://192.168.0.2:8080`**) и в 1 клик добавить любой новый сайт в список обхода или отключить/включить нужный сервис.
