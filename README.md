# Чистая сборка: Прямой интернет для РФ + Сервер в Финляндии для зарубежных ресурсов (ПК Windows 11 + Wi-Fi Tenda TX2)

Готовая, полностью автономная сборка для **Windows 11**, роутера **Tenda TX2** и вашего VPS в **Хельсинки, Финляндия (Debian 12)**.

---

## Как это работает (Строго по вашим требованиям)

1. **Прямой интернет на всех сайтах РФ:**
   - Все российские ресурсы (`*.ru`, `*.рф`, `*.su`, `*.by`, `ya.ru`, Яндекс, ВК, Сбербанк, Т-Банк, Госуслуги, Ozon, Wildberries, Авито, Кинопоиск, Rutube и др.) работают **напрямую через вашего провайдера РФ** как на компьютере, так и по Wi-Fi.
2. **Все зарубежные ресурсы — через ваш сервер в Финляндии (`91.108.239.5`):**
   - YouTube (в 4K без буферизации), Instagram, Telegram, Discord, ChatGPT и **любые другие зарубежные сайты** автоматически идут через ваш сервер в Хельсинки по протоколу `VLESS-Reality XTLS-Vision`.
3. **VPN Happ работает независимо на ваше прямое соединение:**
   - Сборка **не устанавливает виртуальную сетевую карту (`WinTun`)**, **не отключает DHCP на `Ethernet`** и **не включает серверный режим маршрутизатора Windows (`RemoteAccess` / `IPEnableRouter`)**.
   - Поэтому **VPN Happ** на вашем компьютере остаётся полностью свободным и включается/выключается **только по вашему решению** прямо поверх вашего прямого интернет-соединения.
4. **Работает одновременно и на ПК, и по домашнему Wi-Fi (`Tenda TX2`):**
   - Служба открывает в вашей домашней сети `192.168.0.0/24` умный шлюз на порту `2080` (`<IP вашего ПК>:2080`), который также разделяет трафик для телефонов по Wi-Fi: сайты РФ пускает напрямую, а зарубежные — через Финляндию.
5. **Мгновенное восстановление базовых настроек интернета:**
   - Файл **`1-RESTORE-INTERNET.bat`** (или пункт `[2]` в меню) в любой момент за 5 секунд возвращает все сетевые настройки Windows 11 в 100% заводское состояние.

## Пошаговая инструкция по запуску

### Шаг 1. Распакуйте скачанный ZIP-архив
Нажмите правой кнопкой мыши по скачанному архиву $\rightarrow$ **«Извлечь все...»**.

### Шаг 2. Восстановите базовые настройки сети (для починки Happ VPN)
1. Запустите двойным кликом **`1-RESTORE-INTERNET.bat`** (нажмите «Да» в окне Администратора).
2. Когда появится надпись `SUCCESS! ALL NETWORK SETTINGS RESTORED TO WINDOWS 11 DEFAULTS!` — **один раз перезагрузите компьютер**, чтобы драйвер **Happ VPN** перезапустился на чистом сетевом стеке.

### Шаг 3. Запустите шлюз Финляндии (`2-START-FINLAND-GATEWAY.bat`)
1. Откройте двойным кликом **`2-START-FINLAND-GATEWAY.bat`**.
2. В меню нажмите **`1`** *(«ВКЛЮЧИТЬ СЕРВЕР В ФИНЛЯНДИИ (РФ сайты - напрямую, Зарубежные - через Финляндию)»)*.
3. Скрипт автоматически найдёт уже сохранённые на вашем ПК ключи от вашего VPS (`91.108.239.5`) — просто нажмите **`Enter`**, и через 5 секунд всё заработает!
   *(Если ключей нет — введите IP `91.108.239.5`, порт `55971` и пароль от `root`)*.

### Шаг 4. Подключение телефонов по домашнему Wi-Fi (Tenda TX2)
Когда вы включите пункт `[1]`, скрипт покажет на экране локальный IP вашего компьютера (например, `192.168.0.115`) и порт `2080`:
1. На телефоне зайдите в настройки вашей домашней сети **Wi-Fi (Tenda)** $\rightarrow$ **«Настройка прокси»** $\rightarrow$ **«Вручную»**.
2. Укажите **Сервер:** `192.168.0.115` *(IP вашего ПК)* и **Порт:** `2080`.
3. Теперь на телефоне по домашнему Wi-Fi все российские сайты и банки тоже идут напрямую, а все зарубежные — через ваш VPS в Финляндии!
