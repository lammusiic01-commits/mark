# Telegram-бот и мини-приложение

MARK превращается в продукт, который живёт в телефоне: бот пишет сводки, принимает команды, а приложение
внутри Telegram открывается одной кнопкой — чёрный премиум-интерфейс, тактильный отклик, всё крупное под палец.

Документ отвечает на три вопроса: как создать бота, как заставить его работать из России и как объяснить
сотрудникам, что делать в приложении.

---

## 1. Что получается в итоге

| Экран приложения | Что показывает | Откуда данные |
| --- | --- | --- |
| **Сводка** | баланс, клики/расход/конверсии, доля ботов, SEO-балл, алерты, совет | `/api/tg/dashboard/summary` |
| **Рост и SEO** | аудит сайта, автоисправления, GEO по регионам, анализ рынка | `/api/tg/sites/*`, `/api/tg/geo/*`, `/api/tg/market/analyze` |
| **BotShield** | проверка логов, доля фальшивого трафика, потери в рублях, рекомендации | `/api/tg/bots/scan` |
| **Кампании** | метрики, графики, рекомендации по ставкам и применение | `/api/tg/campaigns/*` |
| **Гипотезы** | ICE-приоритет, запуск теста, расчёт результата (z-тест) | `/api/tg/hypotheses/*` |
| **Баланс** | оплата по СБП (QR), тарифы, история операций | `/api/tg/balance`, `/api/tg/payments/*` |
| **Подключения** | каталог сервисов, инструкции «где взять ключ», проверка токенов | `/api/tg/services/*` |
| **Настройки** | агентство, автоматизация, статус бота, AI, диагностика | `/api/tg/settings`, `/api/tg/diagnostics` |
| **Отчёты** | сборка отчёта для клиента, HTML/PDF | `/api/tg/reports/*` |

Команды бота: `/start`, `/menu`, `/status`, `/sites`, `/audit`, `/geo`, `/market`, `/bots`, `/hypotheses`,
`/report`, `/quick`, `/clients`, `/link`, `/help`. Свободный текст бот воспринимает как запрос на аудит.
Автооптимизация, аудит и отчёты продолжат работать по cron — бот только показывает и подтверждает.

## 2. Создание бота (3 минуты)

1. Откройте в Telegram **@BotFather** → `/newbot`.
2. Придумайте имя (например, `AI Маркетолог`) и username, который заканчивается на `bot` (`ai_marketer_bot`).
3. BotFather пришлёт токен вида `7712345678:AAH...` — он понадобится на шаге 4.
4. По желанию: `/setdescription`, `/setuserpic`, `/setcommands` — либо ничего не задавайте, MARK сам
   установит меню команд при старте.

---

## 3. Работа из России: прокси Cloudflare Worker

Прямые запросы к `api.telegram.org` из РФ блокируются. MARK поддерживает прокси: достаточно указать
переменную `MARK_TELEGRAM_API_BASE`, и все вызовы вида `/bot<token>/sendMessage` уйдут через ваш воркер.

1. Зайдите на **dash.cloudflare.com** → *Workers & Pages* → **Create** → **Worker**.
2. Вставьте код из [`deploy/cloudflare-worker/telegram-proxy.js`](../deploy/cloudflare-worker/telegram-proxy.js)
   и нажмите **Deploy**.
3. Скопируйте адрес воркера: `https://tg-proxy.<ваш-аккаунт>.workers.dev`.
4. Пропишите его в окружении сервера MARK:

   ```bash
   MARK_TELEGRAM_API_BASE=https://tg-proxy.<ваш-аккаунт>.workers.dev
   ```

Воркер пересылает только пути `/bot...` и `/file/bot...`, поэтому чужой человек не сможет использовать его
как открытый прокси. Если нужен дополнительный секрет — задайте `SHARED_SECRET` в воркере (см. комментарии
в файле) и передайте такой же заголовок в MARK.

Проверка, что прокси жив:

```bash
curl -s "$MARK_TELEGRAM_API_BASE/bot<ТОКЕН>/getMe" | head -c 200
```

Ответ должен быть `{"ok":true,"result":{...}}`.

## 4. Переменные окружения

| Переменная | Обязательна | Что делает |
| --- | --- | --- |
| `MARK_TELEGRAM_BOT_TOKEN` | да (или подключённый сервис Telegram) | токен от @BotFather |
| `MARK_PUBLIC_URL` | да для кнопки приложения | публичный HTTPS-адрес MARK, например `https://mark.agency.ru` |
| `MARK_TELEGRAM_API_BASE` | для работы из РФ | адрес Cloudflare-воркера (см. шаг 3) |
| `MARK_TELEGRAM_ADMIN_CHAT_ID` | нет | чат, который сразу получает права владельца |
| `MARK_TELEGRAM_DISABLED=1` | нет | полностью выключает бота на этом сервере |

Токен можно не задавать в окружении, а **подключить как сервис**: раздел «Подключения» → *Telegram Bot* →
вставьте токен → «Подключить». MARK расшифрует секрет и поднимет бота при следующем запуске
(или сразу после кнопки «Перезапустить бота» в настройках).

### Локальный сервер без публичного адреса

Кнопка приложения требует HTTPS-адрес. Быстро получить его можно так:

* **Cloudflare Tunnel**: `cloudflared tunnel --url http://localhost:8787` → получите адрес
  `https://<случайный>.trycloudflare.com` и укажите его в `MARK_PUBLIC_URL`.
* **ngrok**: `ngrok http 8787`.

Пока адреса нет, бот работает в режиме команд (`/status`, `/bots`, `/report`), а вместо кнопки приложения
показывает меню команд.

## 5. Запуск и проверка

```bash
# 1. запустите MARK
npm run build && npm start                     # или npm run dev

# 2. убедитесь, что бот поднялся — в логе будет строка:
#    [mark:server] Telegram-бот @ai_marketer_bot запущен, мини-приложение: https://.../#/tg

# 3. откройте бота в Telegram и отправьте /start
#    первый чат автоматически становится владельцем агентства
```

Если бот не поднялся:

| Симптом в логе | Причина | Что делать |
| --- | --- | --- |
| `Токен бота не найден` | нет `MARK_TELEGRAM_BOT_TOKEN` и нет подключённого сервиса | задайте переменную или подключите сервис Telegram |
| `Не удалось запустить бота: ... fetch failed` | нет доступа к api.telegram.org | настройте прокси (шаг 3) |
| `Публичный адрес MARK не задан` | нет `MARK_PUBLIC_URL` | задайте адрес — появится кнопка приложения |
| `Telegram не принял сообщение: chat not found` | пользователь не написал боту первым | пусть сотрудник отправит `/start` |

Проверки из интерфейса: **Настройки → Telegram-бот и приложение** — статус, тестовое сообщение,
перезапуск, приглашение для сотрудника и список чатов с ролями.

## 6. Доступы и роли

* Первый написавший боту чат становится **владельцем** — видит все данные агентства.
* Остальные сотрудники отправляют `/start`; владелец получает запрос «Добавить чат?» с кнопками
  **Разрешить / Отклонить**.
* Роли: `owner` — всё, включая тарифы и доступы; `manager` — данные и действия; `viewer` — только просмотр.
  Меняются в настройках (или через `PATCH /api/telegram/chats/:id`).
* Отозвать доступ: в настройках или командой `/link` → **Удалить чат**.

---

## 7. Проверка подписи Telegram (безопасность)

Приложение отправляет на сервер заголовок `X-Telegram-Init-Data`. MARK проверяет подпись по алгоритму
Telegram (HMAC-SHA256 с секретом `WebAppData`, ограничение по времени 24 часа) и только после этого
отдаёт данные агентства. Если токен бота не задан (локальный режим), сервер помечает сессию как
непроверенную — в настройках приложения это честно показано («без подписи»).

## 8. Проверка бота без реального Telegram

Если нужно убедиться, что бот, команды и кнопка приложения работают, но доступа к api.telegram.org нет
(или не хочется тратить токен), используйте встроенный мок Bot API:

```bash
# терминал 1 — мок вместо api.telegram.org
node apps/server/tests/mock-telegram.mjs 8899

# терминал 2 — MARK с прокси на мок
MARK_TELEGRAM_BOT_TOKEN=1:test \
MARK_TELEGRAM_API_BASE=http://127.0.0.1:8899 \
MARK_PUBLIC_URL=https://mark.example.com \
npm run dev

# терминал 3 — «пользователь» отправляет боту команду
curl -s -X POST -H 'content-type: application/json' \
  -d '{"update_id":1,"message":{"message_id":1,"date":1,"chat":{"id":555001,"type":"private","first_name":"Иван"},"from":{"id":555001,"first_name":"Иван","username":"ivan"},"text":"/start"}}' \
  http://127.0.0.1:8899/__push

# что бот ответил:
curl -s http://127.0.0.1:8899/__inbox
```

Этот же сценарий закрыт автотестами: `cd apps/server && npx vitest run tests/telegram.test.ts` — проверка
подписи initData, разметки сообщений и полного цикла опроса обновлений.

## 9. Что дальше

* Оплата: подключите провайдера СБП (`MARK_SBP_PROVIDER_URL`, `MARK_SBP_MERCHANT_ID`, `MARK_SBP_ACCOUNT`) —
  статус платежа начнёт проверяться автоматически. Без провайдера работает тестовый режим: QR строится,
  зачисление подтверждается кнопкой в приложении или менеджером.
* AI-советник: ключ OpenRouter (`OPENROUTER_API_KEY`) или сервис *OpenAI* в подключениях. Без ключа советы
  собирает движок из ваших цифр — экран никогда не пустует.
* Белая метка: название и цвет агентства из настроек попадают и в бота, и в приложение, и в отчёты.
